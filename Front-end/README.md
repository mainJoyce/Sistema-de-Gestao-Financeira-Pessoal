# FinanceAI — Frontend

Frontend demonstrativo do sistema de gestão financeira pessoal, baseado nas imagens de protótipo de alta fidelidade enviadas.

## Como executar
1. Extraia a pasta `FinanceAI-frontend`.
2. Abra a pasta no VS Code.
3. Abra `index.html` com Live Server (recomendado) ou no navegador.
4. Entre pelo botão de login ou acesse `dashboard.html`.

## Arquivos
- `css/style.css`: layout responsivo, cores, sidebar, cards, tabelas e formulários.
- `js/script.js`: navegação demonstrativa e armazenamento local de transações via `localStorage`.
- Cada tela tem seu próprio arquivo HTML.

## Observação
Esta entrega é somente frontend. Login, cadastro, IA e botões que dependem de servidor são demonstrações visuais e ainda precisam ser integrados ao backend. Os lançamentos de exemplo ficam no navegador local.
